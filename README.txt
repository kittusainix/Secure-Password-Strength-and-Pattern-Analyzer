PASSWORD STRENGTH AND PATTERN ANALYZER
MCA Mini Project — HTML, CSS and JavaScript

FILES
- index.html  : Project page and interface structure
- style.css   : Colors, layout and responsive design
- script.js   : Strength score, pattern checks and recommendations

HOW TO RUN IN VS CODE
1. Download and extract the ZIP file.
2. Open Visual Studio Code.
3. Click File > Open Folder.
4. Select the extracted Password_Strength_Pattern_Analyzer_Project folder.
5. Open index.html.
6. Right-click inside index.html and choose “Open with Live Server” if the Live Server extension is installed.
   OR simply open the folder in File Explorer and double-click index.html to run it in your browser.

FEATURES
- Live password strength score from 0 to 100
- Strength meter and summary dashboard
- Checks length, uppercase, lowercase, number and special character
- Basic checks for common words, sequences and repeated characters
- Dynamic recommendations
- Show/Hide password control
- Responsive layout for laptop and mobile
- Works without a server, database, API key or internet connection

IMPORTANT PRIVACY NOTE
Use a sample password for demonstrations. Do not enter a real password used for your personal accounts. The project runs its checks in the browser and does not upload or save the entered text.

LIMITATIONS
This is a student educational project. Its score is a simple estimate and is not a professional password-security audit. Pattern detection checks only a set of common examples.
